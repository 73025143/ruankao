## 一、计算机组成原理

### 错题 #1｜PC vs IR（我选 IR ❌ → PC ✅）
> 配套动画：`个人/9月4日/CPU指令执行动画.html`（方向键逐步看）

**总循环图（每条指令都走这一圈）：**

```
        ┌─────────────────────────────────────────────────────┐
        │                                                     │
        ▼                                                     │
   ① PC ──"下一条地址给我"──→ ② MAR ──→ ③ 内存对应格子        │
   （书签）                    （报地址）      │                │
                                               ▼               │
   ⑥ PC 自动 +1  ←──（与下面并行）       ④ MDR（转运站）        │
      或被 JMP 改写 ←────★                   │                │
        │                                     ▼               │
        │                              ⑤ IR（当前指令）        │
        │                                     │               │
        │                            ⑦ 译码 → 执行 ───────────┘
        ▼
   回到 ①，直到 HALT     ★ ①⑥ = "跟踪后继指令地址" = PC
```

**示例程序：LOAD 200 / ADD 201 / STORE 202 / JMP 104 / HALT**（等价于 `mem[202]=mem[200]+mem[201]`，即 3+5=8）
- 每轮固定节奏：PC→MAR→内存→MDR→IR，同时 PC+1，然后按操作码执行
- JMP 轮的点睛之笔：执行 JMP = 直接改写 PC（jmp/je/call/ret/断点底层全是这个）

**关键概念防混：**

| 概念 | 是什么 | 装它的寄存器 |
|---|---|---|
| 指令**地址** | 门牌号（101 这种数字） | **PC** 存下一条的门牌号 |
| 指令**本体** | 指令内容（`ADD 201`） | **IR** 存当前这条（来自 MDR，不是来自 PC！） |

**四个选项全辨析（考试爱拿"最接近的"当干扰项）：**

| 选项 | 寄存器 | 存什么 | 为什么不选 |
|---|---|---|---|
| A. 指令寄存器 | IR | 当前指令**本体**（`ADD 201`） | 是内容不是地址 |
| B. 地址寄存器 ⚠️最毒 | MAR | 当前这次访问的内存单元地址 | 也存地址！但只管"眼前这一次读写"（用完就换），不专职跟踪"下一条指令" |
| C. 程序计数器 ✅ | PC | 下一条指令的地址 | 专职导航：自动+1、被 JMP 改写 = "跟踪后继" |
| D. 数据寄存器 | MDR | 与内存交换的数据本身 | 连地址都不是 |

- PC vs MAR 一句话：PC=叫号屏（长期导航"下一位是谁"），MAR=柜员喊号（"这次办 202 号柜"，用完就换）

- **错因**：混淆"存地址"和"存指令"
- **核心**：
  - PC 程序计数器 = 存**下一条指令的地址**（跟踪后继指令）
  - IR 指令寄存器 = 存**当前正在执行的指令本身**
- **一句话记住**：Counter 数地址，Register 装指令
- **开发视角**：gdb 的 rip/eip 就是 PC，断点=拦 PC
- **举一反三**：取指链路 PC→MAR→内存→MDR→IR；指令周期=取指→间址→执行→中断

## 二、操作系统

### 错题 #25｜Linux 权限 751（我选 742 ❌ → 751 ✅）
- **错因**：三类人的权限对错了位
- **核心**：r=4、w=2、x=1；顺序固定 所有者/组/其他
  - 所有者 rwx = 7
  - 组 r-x（读取+运行）= 5
  - 其他 --x（仅运行）= 1
- **做题技巧**：先写三行 rwx 再求和，别口算
- **举一反三**：`ls -l` 十位（类型+rwx×3）；特殊位 SUID=4/SGID=2/sticky=1（4755）；目录 x=可进入

## 三、计算机网络

### 错题 #48｜拖库（我选社工库 ❌ → 拖库 ✅）
- **核心**：黑色产业链 **拖库→洗库→撞库**
  - 拖库 = 从网站数据库**整库导出**用户数据（行为）
  - 洗库 = 清洗提纯变现
  - 撞库 = 拿账号密码去其他网站批量试登录
  - 社工库 = 多方泄露数据汇聚的**查询库**（是物不是行为）
- **一句话记住**："拖"=整库拖走 → 题干"获取整个用户资料"

### 错题 #50+#51｜交换机层次 & 管理对象（连坐 2 题 ❌）
- **错因**：设备与层次、与转发依据没绑死
- **核心表**：

| 设备 | OSI 层 | 转发依据 |
|---|---|---|
| 中继器/集线器 | 物理层 | 信号放大 |
| 网桥/**交换机** | **数据链路层** | **MAC 地址表** |
| **路由器** | **网络层** | IP 路由表 |
| 网关 | 传输层以上 | 协议转换 |

- **一句话记住**：IP=收件地址（跨城），MAC=身份证（同小区）；交换机管 MAC，路由器管 IP
- **开发视角**：docker0 就是网桥；ARP="IP 问 MAC"

## 四、数据库

### 错题 #43｜三级模式对应（我选 A ❌ → D ✅）
- **核心**：越外越近用户，越内越近磁盘

| 层 | 别名 | 对应对象 |
|---|---|---|
| 外模式 | 用户视图/子模式 | **视图 VIEW** |
| 模式 | 概念视图/逻辑模式 | **基本表** |
| 内模式 | 存储视图/物理模式 | **存储文件** |

- **必考延伸（两级映射→两个独立性）**：
  - 外模式↔模式映射 → **逻辑独立性**（改表结构，视图不动）
  - 模式↔内模式映射 → **物理独立性**（换存储方式，表不动）

### 错题 #47｜范式升级链（我选 1NF ❌ → 4NF ✅）
- **错因**：想成"低范式=简单=没有依赖"，实际相反
- **核心链**：
  1NF 属性原子 → 2NF 消**非主属性对码的部分依赖** → 3NF 消**传递依赖** → BCNF 消主属性的部分/传递依赖 → **4NF 消非平凡多值依赖**
- **一句话记住**：部分→传递→主属性→多值；**4NF 是第一个无多值依赖的范式**
- **判断题型**：给 X→→Y（多值依赖）且非平凡 → 需要到 4NF 才消

## 五、软件工程（重灾区，6 题）

### 错题 #28｜白盒覆盖强度（我选语句 ❌ → 路径 ✅）
- **核心排序**：语句 < 判定 < 条件 < 判定/条件 < 条件组合 < **路径**
- **一句话记住**：单选问"覆盖最高"闭眼选路径
- **连考延伸**：McCabe 环路复杂度 **V(G) = E−N+2 = 判定节点数+1**（年年考，正推逆推法都要会）

### 错题 #30｜提高质量靠评审（我选测试 ❌ → 技术评审 ✅）
- **核心**：教材金句"质量不是测出来的，是构建出来的"
  - 技术评审 = **预防性**，贯穿全程（需求/设计/代码评审）
  - 测试 = **检测性**，只能发现缺陷，不能证明无错，更不直接提升质量
- **开发视角**：code review 就是技术评审实例
- **审题**：问"提高质量"→评审；问"发现缺陷/验证"→测试

### 错题 #33+#34｜关键路径（未作答 = 方法未掌握 ⚠️）
- **核心定义**：关键路径 = 起点→终点**最长**路径（决定最短总工期），可能不止一条
- **三步法**：
  1. 正推：节点最早时间 = max(前驱+边权) → 终点即总工期（本题 55）
  2. 逆推：终点最晚=总工期，倒推 = min(后继−边权)
  3. 松弛=最晚开始−最早开始，**松弛 0 的活动**串成关键路径（本题 4 条）
- **铁律**：
  - 压缩工期只能压**关键活动**
  - 压过劲 → 非关键路径变关键
  - 关键路径是**最长**不是最短（反直觉，考试陷阱）
- **行动**：9/6 周日下午找 2 道活动图题动手算，方法必须落地

### 错题 #37｜DFD 四要素（我选加工 ❌ → 控制流 ✅）
- **核心**：DFD = **数据流(箭头) + 加工(圆) + 数据存储(双横线) + 外部实体(矩形)**
- **没有控制流**！if/else 是程序流程图的事，DFD 只关心数据怎么流
- **⚠️ 下午题第一题就是 DFD**：
  - 加工=动词、实体=名词（数据源/潭）、存储=表、流=字段
  - 父子图平衡：父图 1 个加工 ↔ 子图 1 张图，输入输出数据流必须守恒（判分点）

### 错题 #40｜OO 测试层次（我选系统 ❌ → 类 ✅）
- **核心对应**：**类测试 = 面向对象的单元测试**
  - 单元 → 类测试；集成 → 对象交互测试；系统 → 用例驱动测试
- **一句话记住**：OO 世界里"单元"就是类

### 错题 #41｜UML 类图关系（我选依赖 ❌ → 泛化 ✅）
- **核心表**：

| 关系 | 含义 | 图符 |
|---|---|---|
| **泛化** | **特殊/一般（继承）** | 实线+空心三角 |
| 实现 | 接口实现 | 虚线+空心三角 |
| 组合 | 整体-部分·同生共死 | 实心菱形（整体端） |
| 聚合 | 整体-部分·可分离 | 空心菱形（整体端） |
| 关联 | 长期结构关系 | 实线 |
| 依赖 | 临时使用（参数/局部变量） | 虚线箭头 |

- **口诀**：三角都空心，实线继承虚线实现；实心菱=死都不分，空心菱=可拆伙
- **看到"特殊/一般"→ 泛化**；下午题设计模式必画这些关系

## 六、知识产权/法律法规

### 错题 #57｜合理引用（我选 B ❌ → A ✅）
- **⚠️ 错因第一层：审题**——问的是"**不正确**"的叙述！
- **核心规则**：著作权合理使用 = 为介绍/评论/说明问题，**适当引用已发表作品** → 免许可、免报酬
  - B（引用不必征得同意、不付报酬）说法本身**正确**
  - A（可引用未发表作品）说法**错误** → 题目要选 A
- **一句话记住**：合理引用只限**已发表**作品；引未发表的侵犯**发表权**
- **扩展**：软件著作权自创作完成**自动产生**（无需登记）；保护**表达**不保护思想/算法/接口

## 七、专业英语（同篇完形：系统运维主题）

### 错题 #71｜implemented（我选 designed ❌）
- 生命周期链：analysis → design → **implement** → operate → support
- 系统**实施上线**后才进入运维支持期；designed 还没落地

### 错题 #73｜execution（我选 construction ❌）
- day-to-day **execution** 日常执行业务流程
- construction/implementation 是开发期词汇，别混入运维期

### 错题 #75｜triggered（我选 produced ❌）
- be **triggered** by = 由……触发
- 运维项目都由故障/事件/机会**触发**启动，produced 完全不符

### 词汇沉淀（考前再背一遍）
implemented 实施 | execution 执行 | triggered 触发 | decompose into 分解为 | encountered 遇到 | operation 运行 | support 支持/维护

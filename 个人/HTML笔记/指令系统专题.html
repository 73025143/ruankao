① 一条指令长什么样 instruction format

一条机器指令 = 操作码（OP） + 地址码。一个是"干什么"，一个是"对谁干"。

操作码 OP ：干什么（加 / 减 / 传送 / 跳转 / 停机） 地址码 A ：对谁干（操作数地址 / 结果地址 / 下条指令地址） 例： ADD R1, [1000H] → 把内存 1000H 的内容加进 R1 操作码 地址码
概念含义考点
操作码位数决定能表示多少种操作n 位操作码 → 最多 2n 条指令
指令字长一条指令占的二进制位数定长（简单、译码快）/ 变长（省空间）
定长操作码所有指令操作码位数相同译码简单，但指令总数受限
扩展操作码常用指令用短码、不常用用长码类似哈夫曼：短码省长度、长码扩展容量
🔑 送分点：操作码 n 位 → 2n 条指令。8 位操作码 = 最多 256 条指令。

② 按"地址码个数"分类（三/二/一/零地址指令）

类型形式含义例子
三地址a = b op c两个操作数、一个结果，各占一地址ADD R1,R2,R3
二地址a = a op b结果覆盖其中一个操作数（最常见）ADD R1,R2（R1←R1+R2）
一地址ac = ac op x另一个操作数隐含在累加器 ACADD X（AC←AC+X）
零地址op无操作数，或操作数隐在堆栈顶NOP / RET / 栈运算
💡 地址码越多 → 指令越长、结构越复杂；RISC 偏爱少地址码 + 寄存器。一地址指令靠 AC，零地址指令常配堆栈（如堆栈式计算机）。

③ 寻址方式（找操作数的方式 · 必考） addressing modes

核心就一句话：指令里的"形式地址"，怎样变成操作数真正的地址（有效地址 EA）？

寻址方式有效地址 / 操作数位置特点 / 用途
立即寻址操作数就在指令里（无 EA）最快（不访存取操作数） / 但操作数固定不能改
直接寻址EA = A形式地址就是有效地址 / 访存 1 次
间接寻址EA = (A)A 单元里装的是 EA / 访存 ≥2 次，灵活但慢（一次间接）
寄存器寻址操作数在寄存器里快（不访存） / 寄存器数量有限
寄存器间接EA = (R)寄存器里装的是 EA / 比内存间接快
变址寻址EA = (IX) + A变址寄存器内容 + 形式地址 / 适合数组、循环
相对寻址EA = (PC) + APC 内容 + 形式地址 / 适合转移指令、程序浮动
基址寻址EA = (BR) + A基址寄存器 + 形式地址 / 适合多道程序重定位
堆栈寻址EA = (SP)由栈指针给出 / 零地址指令常用
⚠️ 变址 vs 基址（最爱混）：
· 变址寻址：变址寄存器内容可变（循环里自增），形式地址不变 → 面向数组下标。
· 基址寻址：基址寄存器内容不变（程序装入时定），形式地址变 → 面向程序重定位。
一句话：变址——寄存器变、地址定；基址——寄存器定、地址变。
💡 执行速度排序（取操作数）：立即 > 寄存器 > 直接 > 间接。访存次数：立即 0 次、直接 1 次、一次间接 2 次。
【例题 · 变址/相对 求 EA】某机指令中的形式地址 A = 20H。① 若采用变址寻址，变址寄存器内容 = 1000H，则有效地址 EA = ? ② 若采用相对寻址，PC 当前值 = 2000H，则 EA = ?
点击看答案
① 变址：EA = (IX) + A = 1000H + 20H = 1020H
② 相对：EA = (PC) + A = 2000H + 20H = 2020H
🔑 两式长得像，区别只在"加的是谁"：变址加变址寄存器、相对加 PC、基址加基址寄存器。
【例题 · 寻址方式辨速度】下列寻址方式中，获取操作数速度最快的是（　　）
A. 直接寻址　　B. 间接寻址　　C. 立即寻址　　D. 寄存器间接寻址
点击看答案
C。立即寻址的操作数直接写在指令里，取指时一并拿到，不需要再访存，所以最快。
❌ 直接寻址要访存 1 次取操作数；❌ 间接/寄存器间接还要多绕一层。
🔑 排序记牢：立即（0 次访存）> 寄存器（不访存）> 直接（1 次）> 间接（≥2 次）。

④ CISC vs RISC（机考模拟第 1 题就是它） complex / reduced instruction set

根源：早期一味堆指令（CISC），后来发现复杂指令很少用、还拖慢速度 → 反其道而行，只留简单高频指令 + 流水线 + 好编译器（RISC）。

CISC 复杂指令集

  • 指令数量多（100~250 条）
  • 指令功能强、复杂
  • 指令长度可变、格式多样
  • 寻址方式多
  • 任意指令都能访存
  • 控制器以微程序控制为主
  • 通用寄存器相对少
  • 代表：Intel x86、VAX

RISC 精简指令集

  • 指令数量少（< 100 条）
  • 指令功能简单、规整
  • 指令长度固定、格式少
  • 寻址方式少
  • 只有 load/store 访存
  • 控制器以硬布线（组合逻辑）为主
  • 通用寄存器大量
  • 代表：ARM、MIPS、RISC-V
对比项CISCRISC
指令数量 / 复杂度多、功能强少、简单
指令长度可变、格式多样定长、格式少
寻址方式多、复杂少、简单
访存限制任意指令可访存只有 load/store 访存
控制器微程序控制硬布线控制
通用寄存器数相对少大量
执行周期长短不一、难流水线化大多一个周期、适合流水线
编译优化难生成高效代码易被编译器优化
典型代表Intel x86、VAXARM、MIPS、RISC-V
⚠️ 三个最爱考的坑：
1. "指令种类多、功能强" = CISC，别扣给 RISC（机考第 1 题 B 就错在这）。
2. "大量通用寄存器" = RISC（运算在寄存器间进行，所以寄存器多）。
3. 控制器：CISC 用微程序、RISC 用硬布线——这对立常单独出单选。
🔑 一句话口诀：
RISC = 少（指令少）、定（定长）、简（寻址少）、多（寄存器多）、硬（硬布线）、流（善流水线）；
CISC = 多、变、杂、微（微程序）、少寄存器。
【真题原文 · 机考模拟第 1 题】以下关于 RISC（精简指令集计算机）特点的叙述中，错误的是（　　）
A. 对存储器操作进行限制，使控制简单化　　B. 指令种类多，指令功能强
C. 设置大量通用寄存器　　D. 选取使用频率较高的一些指令，提高执行速度
点击看答案
B（"指令种类多、功能强"是 CISC 的特点）。
✅ A：RISC 只有 load/store 访问存储器，访存受限 → 控制简单
❌ B：RISC 是"指令种类少、功能简单"，说"多、强"是 CISC
✅ C：RISC 运算在寄存器间进行 → 需要大量通用寄存器
✅ D：RISC 只保留高频指令（砍掉低频复杂指令），提高执行速度
🔑 诀窍：看到"指令多、功能强"就往 CISC 想，那正是 RISC 的反面。
【真题风格 · 反向问 CISC】以下关于 CISC（复杂指令集计算机）的叙述中，错误的是（　　）
A. 指令数量多，使用频率相差悬殊　　B. 指令长度可变，寻址方式多
C. 控制器以硬布线控制为主　　D. 各种指令都可访问存储器
点击看答案
C。硬布线（组合逻辑）是 RISC 的，CISC 用微程序控制。
✅ A：CISC 指令多，且"20% 指令占 80% 使用率"（帕累托）
✅ B：CISC 指令变长、寻址多（RISC 才定长、寻址少）
✅ D：CISC 任意指令都能访存（RISC 只有 load/store）
🔑 控制器归属是高频考点：CISC→微程序，RISC→硬布线。

⑤ 指令流水线（概览 · 详细见动画） instruction pipeline

流水线是把"取指→译码→执行→写回"这几步像装配线一样重叠起来，让多条指令同时处于不同阶段，从而提速。RISC 指令规整，天生适合流水线。

核心公式： 执行 n 条指令、k 段流水线 → 总时间 = (k + n − 1) × Δt 吞吐率 TP = n / 总时间 建立时间 = k × Δt 加速比 S = 串行时间 / 流水线时间 效率 E = 时空图有效面积 / 总面积

⑥ 真题实战（先选，再点开） practice

题1（操作码位数）：某计算机指令的操作码固定为 6 位，则该计算机最多可有（　　）种操作。
A. 6　　B. 36　　C. 64　　D. 128
点击看答案
C。n 位操作码 → 2n 种 = 26 = 64 种。
🔑 记住"几位操作码就是 2 的几次方"，别拿位数直接当选。
题2（扩展操作码 · 经典）：某机指令字长 16 位，每个地址码 4 位，采用扩展操作码。若三地址指令有 15 条，则二地址指令最多有（　　）条。
A. 14　　B. 15　　C. 16　　D. 32
点击看答案
C（16 条）。三步走：
① 三地址指令占 3×4 = 12 位地址码，剩 4 位给操作码 → 共 24 = 16 种编码
② 三地址用掉 15 种，剩 1 种留作扩展
③ 二地址少一个地址码，多出的 4 位并进操作码 → 那 1 种 × 24 = 16 条二地址指令
🔑 扩展操作码的算法：剩余编码数 × 2新释放的地址位数。短码给常用指令，长码给更多指令。
题3（寻址方式）：指令中的形式地址为 A，操作数存放在由 A 指示的内存单元所指向的单元中，这种寻址方式是（　　）
A. 立即寻址　　B. 直接寻址　　C. 间接寻址　　D. 寄存器寻址
点击看答案
C. 间接寻址。EA = (A)——A 单元里装的是"操作数的地址"，要再访存一次才拿到操作数。
❌ A 立即：操作数就在指令里；❌ B 直接：EA=A，A 就是操作数地址（不绕第二层）；❌ D 寄存器：操作数在寄存器里。
🔑 "指向……的单元"= 多绕一层 = 间接。
题4（CISC/RISC 综合）：下列叙述中，不属于 RISC 特点的是（　　）
A. 指令长度固定，格式少，寻址方式少
B. 只有 load/store 指令访问存储器
C. 控制器采用微程序控制，指令功能强
D. 设置大量通用寄存器，采用流水线技术
点击看答案
C。RISC 用硬布线控制、指令功能简单；"微程序控制 + 功能强"是 CISC。
✅ A、B、D 全是 RISC 的正解特点。
🔑 这题几乎把 CISC/RISC 对立点考全了，会这题，同类全通。
题5（一地址/零地址）：下列指令中，通常属于零地址指令的是（　　）
A. ADD R1, R2　　B. PUSH　　C. MOV R1, #5　　D. JMP 2000H
点击看答案
B. PUSH。零地址指令无显式操作数，操作数隐含在堆栈（由 SP 给出），PUSH/POP 是典型。
❌ A 二地址、❌ C 含立即数、❌ D 含转移地址，都不是零地址。
🔑 零地址 = 操作数隐在堆栈，靠 SP 定位。

🔑 结论：指令系统这块上午必考 1~2 分。核心就三样——操作码位数算指令数、寻址方式辨 EA、CISC/RISC 对立点。全吃透即可。
本专题总收：
① 指令 = 操作码 + 地址码；n 位操作码 → 2n 条指令；
② 按地址码个数分：三 / 二 / 一（隐含 AC）/ 零（隐含堆栈）；
③ 寻址方式：立即(0次访存)、直接(EA=A)、间接(EA=(A))、寄存器、变址(EA=(IX)+A,数组)、相对(EA=(PC)+A,转移)、基址(EA=(BR)+A,重定位)；速度快慢：立即>寄存器>直接>间接；
④ CISC：多、变、杂、微程序、少寄存器；RISC：少、定、简、多寄存器、硬布线、只有 load/store 访存、善流水线；
⑤ 流水线：总时间 =(k+n−1)×Δt，详见流水线动画。

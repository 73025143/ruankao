原码

  • 最高位符号：0 正 / 1 负，其余 = 绝对值
  • 0 有两种：+0=00000000、-0=10000000
  • 范围：-127 ~ +127

反码

  • 负数 = 原码数值位按位取反（符号位不动）
  • 正数反码 = 原码，0 也有 ±0 两种
  • 它是算补码的中间步骤

补码

  • 负数 = 反码末位 +1（取反加一）
  • 0 唯一、多表示一个 -128（`10000000`）
  • 减法转加法：`[X-Y]补=[X]补+[-Y]补`，机器用补码

移码

  • 正负都一样：移码 = 补码符号位取反（=真值+128）
  • 移码首位：1 表正、0 表负（与补码相反）
  • 编码大小 = 数值大小，浮点阶码专用
  • 0 唯一：10000000

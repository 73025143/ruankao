### ❌ 错题精讲

**#1（2024上）CPU 中跟踪后继指令地址的寄存器是？** 我选 IR ❌ → **PC** ✅
- 题眼拆解：**跟踪**（一直更新）+ **后继指令**（下一条）+ **地址**（门牌号，不是指令本体）
- 一句话：**PC=叫号屏（下一条的门牌号）**；IR=当前正在读的这行字
- 流程环：`PC→MAR→内存格子→MDR→IR`，同时 **PC 自动+1**，译码执行，循环到 HALT
- JMP 的本质 = **改写 PC**（jmp/je/call/ret/调试断点，底层全是在改 PC）

四选项辨析：

| 选项 | 寄存器 | 存什么 | 为什么不选 |
|---|---|---|---|
| A. 指令寄存器 | IR | 当前指令**本体** | 是内容不是地址 |
| B. 地址寄存器 ⚠️最毒 | MAR | 当前这次访问的地址 | 也存地址！但只管"眼前这一次读写"，不专职跟踪下一条 |
| C. 程序计数器 ✅ | PC | 下一条指令的地址 | 自动+1、被 JMP 改写 = "跟踪后继" |
| D. 数据寄存器 | MDR | 交换的数据本身 | 连地址都不是 |

- 防混核心表：

| 概念 | 是什么 | 装它的寄存器 |
|---|---|---|
| 指令**地址** | 门牌号（101 这种数字） | **PC** 存下一条的门牌号 |
| 指令**本体** | 内容（`ADD 201`） | **IR**（来自 MDR，不是来自 PC！） |

- 举一反三：考 MAR="CPU 访存的地址寄存器"；考 PSW="条件转移的标志位依据"；指令 = **操作码（干啥）+ 操作数（对谁）**

### 📌 专题：CPU 组成（教材 1.1.2）

**CPU 四大功能**：程序控制（管执行顺序）｜操作控制（产生操作信号）｜时间控制（控时序）｜数据处理（最根本）

**CPU = 运算器 + 控制器 + 寄存器组 + 内部总线**

运算器（做运算，执行部件）：

| 部件 | 干什么 | 一句话 |
|---|---|---|
| ALU 算术逻辑单元 | 加/减/乘/除 + 与/或/非/比较 | 真正的算盘 |
| AC 累加器 | 给 ALU 当工作区、暂存结果 | 算盘上正在拨的珠子 |
| DR 数据缓冲寄存器 | 内存↔CPU 中转 + 速度缓冲 | 中转站 |
| PSW 状态条件寄存器 | 标志位：C进位 V溢出 Z为零 N为负 I中断 D方向 | 结果的脸书 |

控制器（指挥，管自动化）：

| 部件 | 干什么 | 一句话 |
|---|---|---|
| IR 指令寄存器 | 存当前指令**本体** | 正在读的这行字 |
| PC 程序计数器 | 存**下一条指令地址**，自动+1 | 叫号屏 |
| AR 地址寄存器 | 暂存本次访问的内存地址 | 这次的门牌号 |
| ID 指令译码器 | 拆操作码、发控制信号 | 翻译官 |

**记忆口诀**：运算器 = **算盘子**（ALU）+ **累加盘**（AC）+ **状态脸**（PSW）+ **中转**（DR）；控制器 = **IR 念、PC 指、AR 查、ID 翻**
**防混铁律**：PC 存**地址**、IR 存**内容** —— PC 答"接下来去哪"，IR 答"现在读的啥"

**多核 vs 单核多线程**：多核=同一时刻真并行；单核多线程=交替执行只是切换快。多核要发挥性能需 OS 合理调度 + 应用并行线程

### 📌 专题：数据编码 原码/反码/补码/移码（教材 1.1.2）

**概念先分清**：负数 = 真值（数学概念）；原/反/补/移 = 机器数（同一负数的 4 种二进制写法）。现代计算机**存储/计算统一用补码**。

**核心一条链（负数，以 -45 为例，8 位）**：

| 码制 | -45 | 规则 |
|---|---|---|
| 原码 | `10101101` | 符号位 1 + 绝对值 0101101 |
| 反码 | `11010010` | 原码数值位**取反**（符号位不动） |
| 补码 | `11010011` | 反码**+1**（=原码取反加一） |
| 移码 | `01010011` | **补码符号位取反** |

> **正数三码相同**：+45 原=反=补=`00101101`；移码=翻符号位=`10101101`。只有负数才变码！

**互转快捷表（只对负数）**：

| 转换 | 操作 |
|---|---|
| 原码 ↔ 反码 | 数值位取反 |
| 反码 → 补码 | +1 |
| 补码 ↔ 原码 | **取反加一（双向通用，来回一样）** |
| 补码 ↔ 移码 | 符号位取反 |

**真值↔二进制**：整数=**除2取余倒序**；小数=**乘2取整正序**；速算用位权拆解 `45=32+8+4+1=101101`

**必考特性（送分点）**：
- **补码 0 唯一**：`[+0]补=[-0]补=00000000`（原码反码有 ±0 两种）
- **补码多表示一个最小负数**：n 位整数多一个 **-2^(n-1)**，纯小数多一个 **-1**
- **`10000000` = -128**（原码= -0，反码= -127，**补码= -128**，同一编码不同码含义不同！）
- 为什么多一个：0 少占一个编码 → 符号位 1 的 2^(n-1) 个编码全给负数 → 最小值 `100...0` 真值=2^(n-1)-2^n=-2^(n-1)

**定点范围完整表（n 位，1 符号 + n-1 数值）**：

| 码制 | 定点整数 | 定点小数 |
|---|---|---|
| 原码/反码 | -(2^(n-1)-1) ~ +(2^(n-1)-1) | -(1-2^-(n-1)) ~ +(1-2^-(n-1)) |
| 补码/移码 | **-2^(n-1)** ~ +(2^(n-1)-1) | **-1** ~ +(1-2^-(n-1)) |

> 8 位代入：整数 原/反 -127~+127，补/移 **-128~+127**；小数 原/反 ±0.9921875，补码负侧可到 **-1**
> 规律：**补码/移码负数多一个**（整数多 -2^(n-1)，小数多 -1）；原码/反码正负对称、够不到边界

**真题对应**：
- #2（2024上）减法用 **补码的二进制加法器**（`[X-Y]补=[X]补+[-Y]补`，硬件只做加法）
- #3（2024上）**仅补码能表示 -1**（纯小数版的多一个）
- #4（2024上）浮点尾数补码规格化：M≥0 时 `0.1xxx`，M<0 时 `1.0xxx`（数符与小数点后第一位**相异**）

### 📌 专题：定点小数 + 浮点衔接

**定点小数定义**：小数点固定在**符号位后、最高数值位前**，最高位仍是符号位（0 正 1 负）。数值位权值 = 2^-1、2^-2、…（0.5、0.25、…），n 位小数部分占 **n-1 位，精度 = 2^-(n-1)**（8 位→7 位小数、最小刻度 1/128）

**编码规则**：与定点整数**完全一样**（正数三码相同、负数取反加一），例 -0.5：原 `1.1000000` 反 `1.0111111` 补 `1.1000000`

**溢出**：结果 > +(1-2^-(n-1)) 或 < -1（补码）即溢出；判断 = **符号位与次高位进位不同**

**⚠️ 最重要：定点小数 = 浮点数的尾数**
- 浮点格式 `阶符|阶码(纯整数)|数符|尾数(纯小数)`，即 `N = 尾数 × 2^阶码`
- **既有整数又有小数的数**（如 83.125 = 1010011.001₂ = 0.1010011001×2^7）：整数部分被**阶码吸收**，尾数永远是纯小数
- **阶码（移码）管范围，尾数（补码）管精度**
- 补码尾数**规格化判断**：**数符与小数点后第一位【相异】** = 规格化（M≥0 → `0.1xxx`；M<0 → `1.0xxx`）

### ✅ 速记
- PC→MAR→内存→MDR→IR + PC+1 → 执行 → 循环
- 断点 = 拦 PC ｜ 跳转 = 改 PC
- 编码口诀：**正数三码相同；负数反码取反、补码取反加一、移码翻符号位；补码 0 唯一、多一个最小负数（整数 -2^(n-1) / 小数 -1）、减法转加法**

| **泛化** | **特殊/一般（继承）** | 实线+空心三角 |
| 实现 | 接口实现 | **虚线**+空心三角 |
| 组合 | 整体部分·同生共死 | **实心**菱形（整体端） |
| 聚合 | 整体部分·可分离 | 空心菱形（整体端） |
| 关联 | 长期结构关系 | 实线 |
| 依赖 | 临时使用 | 虚线箭头 |

- 口诀：三角都空心，实线继承虚线实现；实心菱=死都不分
- 看到"特殊/一般"→泛化；下午题设计模式必画

### ✅ 速记（做对的也别丢）
- 维护四类：环境变了=**适应性**；修 bug=改正性；加功能=完善性；防未来=预防性（#31）
- 不符战略/市场变了/预算超支=**商业风险**（#32）
- SA=**自顶向下逐步分解**（#35）
- Observer=**一对多依赖，变更自动通知**（#42）
- 系统测试→需求阶段；集成测试→概要设计；单元测试→详细设计/编码

### ❌ 错题精讲

**#57（2024上）学术论文引用的不正确叙述？** 我选 B ❌ → **A** ✅
- ⚠️ 错因第一层：**审题**——问的是"**不正确**"项！

- 记：引用只能**已发表**；"未发表"三个字出现就是错

### ❌ 错题精讲（2024上 #71–75，系统运维主题）

生命周期链：**analysis → design → implement → operate → support**

- **#71**：系统 **implemented**（实施上线）后才进入运维期（designed 还没落地）
